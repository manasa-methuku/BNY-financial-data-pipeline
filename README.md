# Quant Backend Engine — Bank of New York

Backend Python developer on the Core Calculation Engine team at Bank of New York, building and maintaining the systems that power quantitative financial calculations across risk, pricing, and performance analytics.

## Role

Part of the core engineering team responsible for the backend infrastructure
that drives quantitative calculations at enterprise scale. Focus areas include
backend Python services, calculation pipeline reliability, data integrity, and
system performance.

## Tech Stack

- Python (core language)
- Snowpark (data processing within Snowflake ecosystem)
- SQL
- Apache Kafka (event-driven data flows)
- REST APIs / FastAPI
- Docker
- GitLab CI/CD

## Key Focus Areas

- Building and maintaining backend Python services that feed clean, validated
  financial data into the core calculation engine
- Developing calculation pipeline components for risk, pricing, and
  performance analytics workflows
- Ensuring data integrity and reliability at the input layer of quantitative
  calculation systems
- Writing performant, well-tested Python code aligned to engineering standards
  of a large financial institution
- Collaborating with quant analysts to translate financial calculation
  requirements into backend system implementations

## Domain

- Quantitative finance backend infrastructure
- Risk and pricing calculation systems
- Enterprise-scale financial data pipelines
- Backend services for quant analytics teams
